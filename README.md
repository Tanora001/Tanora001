## 三条底线

**本机优先** —— 对话、语音、记忆都留在你自己的机器上。自托管不是姿态，是默认路径。

**契约先行** —— 插件、世界、能力共用一份契约；往里加东西，不用改内核。

**不表演** —— 能力边界写清楚：能做什么、暂时不能做什么。宁可少说，也不装作会。
